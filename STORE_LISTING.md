# Chrome Web Store listing: PinPoint Feedback

**Name:** PinPoint Feedback

**Short description (max 132 characters):**
Click anywhere on a website, pin a comment, export a PDF punch list. No account needed, and your data never leaves your device.

**Category:** Developer Tools (alternative: Productivity)

**Language:** English

---

## Detailed description

Website feedback without the email chaos.

PinPoint Feedback lets your clients point at exactly what they want changed on a live website, with no sign-up, no logins and no screenshots pasted into emails.

**How it works**
1. Open the website and click the PinPoint icon.
2. Click any element on the page: a headline, a button, an image.
3. Type what should change and optionally mark it low, medium or high priority.
4. Export a clean PDF punch list with every comment, its page, a screenshot and its status.

**Built for freelance web designers and their clients**
• Numbered pins stay on the page, so you can come back later and see every note in place
• Each comment captures a cropped screenshot of the exact spot
• Mark items done as you work through the list
• Comments are grouped by page and organized into a project per website
• Export as PDF, CSV (for spreadsheets or task tools) or copy as plain text

**Private by design**
• No account and no sign-up
• No servers and no tracking. Everything is stored locally in your browser
• It only runs on a tab when you click the icon, and it can't read your other tabs or browsing history

**Free plan:** 1 project and 15 comments, enough to try it on a real client site.

Tip: press Alt+Shift+P to turn comment mode on or off.

## Single purpose statement (for the Privacy tab)

PinPoint Feedback lets a user place comments on elements of the web page in the current tab and export them as a feedback list (PDF/CSV/text).

## Permission justifications

- **activeTab:** Runs the commenting overlay and takes a screenshot of the current tab, only after the user clicks the extension icon.
- **scripting:** Injects the commenting overlay (pins and note box) into the tab the user activated.
- **storage:** Saves the user's comments, screenshots and project names locally on their device.
- **downloads:** Saves the PDF and CSV exports the user requests.

**Remote code:** No. All code, including the PDF library, is packaged in the extension.

**Data usage:** The extension does not collect or transmit any user data.
